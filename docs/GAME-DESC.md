สำหรับเด็ก ป.1 การทำ **Interactive Web App** ต้องตัดภาระเรื่องการอ่านข้อความยาวๆ ทิ้งไป แล้วแทนที่ด้วย **"การฟังเสียง (Audio-driven)"**, **"ภาพการ์ตูนปุ่มใหญ่"**, และ **"กลไก Gamification (สะสมดาว/ปลดล็อกด่าน)"**

---

### โครงสร้างและเกมเพลย์หลัก (แบ่งเป็น 3 โหมด)

* **โหมด 1: "แตะตามเสียง" (Listen & Tap) — แปลงจากข้อ 7–29 และ 33–44**

* **รูปแบบ:** หน้าจอมีตัวการ์ตูนสัตว์ถือป้ายพินอินตัวใหญ่ๆ 3 ตัว (เช่น `g`, `k`, `h`)


* **การทำงาน:** เมื่อเริ่มรอบ ระบบจะเล่นเสียงพูดชัดๆ ทันที เช่น *"เกอ"* (มีปุ่มรูปลำโพงใหญ่ให้กดฟังซ้ำได้เรื่อยๆ)


* **การโต้ตอบ:** เด็กแตะตัวอักษรที่ตรงกับเสียง หากถูก จะมีเอฟเฟกต์พลุกระดาษและเสียงเอฟเฟกต์ชม ("เฮ้!", "เยี่ยมมาก") หากผิด ตัวการ์ตูนจะส่ายหัวเบาๆ และเปิดโอกาสให้กดใหม่


* **โหมด 2: "ลากต่อขบวนรถไฟ" (Drag & Drop Sequence) — แปลงจากข้อ 1–6**

* **รูปแบบ:** หัวรถไฟวิ่งเข้ามาพร้อมโบกี้ว่าง 4 ช่อง มีตัวบล็อกพินอินหลากสีลอยอยู่ด้านล่าง (เช่น `b`, `p`, `m`, `f`)


* **การทำงาน:** ให้เด็กลากบล็อกตัวอักษรมาวางเรียงลำดับให้ถูกต้องบนโบกี้รถไฟ เมื่อเรียงถูก รถไฟจะบีบหวูด "ปู๊นๆ" แล้วแล่นออกไป


* **โหมด 3: "เปิดกล่องสมบัติ/จับคู่" (Audio Card Matching) — สำหรับสระผสม ข้อ 36–53**

* **รูปแบบ:** มีการ์ดคว่ำหน้า 4–6 ใบ
* **การทำงาน:** ใบหนึ่งเปิดแล้วมีเสียงอ่านสระ (เช่น "ไอ") อีกใบเป็นรูปตัวอักษรพินอิน (`ai`) ให้เด็กเปิดจับคู่เสียงกับรูปตัวอักษร

### UX / UI Guideline สำหรับเด็ก ป.1

* **No Text Reading:** ไม่ใช้โจทย์ภาษาไทยที่เป็นประโยคยาว เช่น *"พยัญชนะพินอินตัวใดอ่านออกเสียงว่า..."* ให้ใช้ **ไอคอนรูปปากพูด/ลำโพง** แล้วเปิดเสียงเล่นอัตโนมัติ (Auto-play voice)


* **Touch Friendly:** ปุ่มต้องใหญ่มาก ขอบมน สีสดใส (Contrast สูง) เหมาะสำหรับนิ้วเด็กจิ้มบนแท็บเล็ตหรือจอสัมผัส
* **Instant Feedback:** เสียง Effect ตอบสนองทันที (Ding-dong ตอนถูก, Boing ตอนผิด) พร้อม Visual สั่นดุ๊กดิ๊ก
* **Bite-sized Stage:** ในเอกสารมี 53 ข้อ ให้แบ่งย่อยเป็นแผนที่ผจญภัย (World Map) ด่านละ 5–6 ตัวอักษร เช่น:


* *Island 1:* แก๊งริมฝีปาก `b, p, m, f`

* *Island 2:* แก๊งปลายลิ้น `d, t, n, l`

* *Island 3:* สระเดี่ยว 6 พี่น้อง `a, o, e, i, u, ü`

* *Island 4:* ป่าสระผสม

### Tech Stack แนะนำสำหรับการพัฒนา

* **Frontend Framework:**
* **Blazor WebAssembly:** ใช้ทำ UI dashboard, แผนที่ด่าน, ระบบบันทึกคะแนน/ดาว (Local Storage)
* **Phaser.js / Pixi.js (หรือ HTML5 Canvas):** หากต้องการแอนิเมชันลื่นไหล สไตล์เกมแฟลช ตกปลา ลากปล่อย หรือระเบิดเอฟเฟกต์


* **Audio Handling:**
* ใช้ **Web Audio API** หรือไลบรารีอย่าง **Howler.js** เพื่อแก้ปัญหา Latency ของเสียงและรองรับการพรีโหลดไฟล์เสียงล่วงหน้า (Preload assets) เพื่อไม่ให้เด็กสะดุดรอโหลดเสียง


* **Asset:**
* ภาพกราฟิกเวกเตอร์ SVG (ปรับขนาดตามจอแท็บเล็ตได้ไม่แตก)
* ไฟล์เสียงพากย์ MP3 ภาษาจีนสำเนียงชัดเจน ตัดสั้นเฉพาะพยางค์นั้นๆ

### สรุปหลักการเลือกใช้ Mode ให้จำง่าย

* **โหมด Train Sequence (ต่อขบวนรถไฟ):** ใช้เฉพาะ **Stage 1–6 (พยัญชนะกลุ่มแรก)** เพราะมีโจทย์เรื่อง "เรียงลำดับพยัญชนะถูกต้อง" อยู่ชัดเจน


* **โหมด Card Match (จับคู่การ์ด):** เหมาะเป็นพิเศษกับ **Stage 10–14 (สระผสม)** ช่วยให้เด็กเห็นการนำสระ 2 ตัวมารวมกัน


* **โหมด Listen & Tap (แตะตามเสียง):** เป็น **Core Mode ที่มีอยู่ในทุกสเตจ (Stage 1–14)** สำหรับวัดผลการฟังเสียงเดี่ยวๆ
